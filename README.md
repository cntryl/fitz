# fitz

A high-performance, multi-scheme message broker (notice://, stream://, queue://, rpc://, inbox://).

Status: early prototype. See `todo.md` for the current prioritized roadmap and `docs/` for design/specs.

## quick start

- Requirements: Rust stable, cargo
- Run tests: `cargo test`
- Lint: `cargo fmt --all -- --check` and `cargo clippy -D warnings`

## links

- Roadmap: `todo.md`
- Design: `docs/design_doc.md`
- Specs: `docs/notice_spec.md`, `docs/stream_spec.md`, `docs/queue_spec.md`, `docs/rpc_spec.md`
