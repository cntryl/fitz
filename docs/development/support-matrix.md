# Support Matrix

This matrix tracks officially validated environments and compatibility expectations.

## Runtime Support

- Linux x86_64: primary target
- Linux arm64: secondary target after validation
- macOS and Windows: development and test support, not production baseline

## Transport Support

- WebSocket: supported
- TCP framed: supported
- HTTP admin surface: supported

See sibling repositories for language-specific client maturity and release cadence.
