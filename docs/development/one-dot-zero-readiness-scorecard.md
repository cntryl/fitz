# One Dot Zero Readiness Scorecard

Use this scorecard for go or no-go decisions.

## Correctness

- Storage invariants documented and validated.
- Recovery behavior validated for expected failure classes.
- Route dispatch and permissions validated across domains.

## Operations

- Runbook used successfully in staging incidents.
- Alerts validated with fault injection.
- Upgrade and rollback rehearsed.

## Compatibility

- Breaking-change process followed.
- Migration docs complete and tested.
- Client compatibility notes published.

## Documentation

- Root docs index complete and accurate.
- Reading paths tested end to end.
- No broken links in critical docs.
