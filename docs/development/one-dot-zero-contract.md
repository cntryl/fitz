# One Dot Zero Contract

This document defines what must be true before declaring Fitz 1.0 readiness.

## Required Commitments

1. Stable compatibility policy and migration guarantees.
2. Clear durability and recovery contract that is test-backed.
3. Production runbook and release checklist proven in real operations.
4. Documented support matrix and deprecation policy.

## Scope

This contract covers server behavior and required operational safety docs. Client SDK release timing may vary by language.
